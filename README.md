# Bot Telegram: encoder H.264 / H.265 (hasta 2 GB)

1. Sube esta carpeta a un repo de GitHub y abre un Codespace.
2. Crea los 3 secrets (Settings → Codespaces → Secrets, o te los pedirá al crear el Codespace):
   - TELEGRAM_BOT_TOKEN (@BotFather)
   - TELEGRAM_API_ID y TELEGRAM_API_HASH (https://my.telegram.org → API development tools)
3. Cuando termine de construirse, en la terminal:

       ./run.sh

Si cambias secrets, reconstruye o reinicia el Codespace.
